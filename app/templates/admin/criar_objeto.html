Campos do Objeto

Defina os campos que cada registro deste objeto terá. Um campo por linha, no formato: nome:tipo:rótulo

Tipos suportados:

  • text - Texto curto (input)
  • textarea - Texto longo (área de texto)
  • number - Número
  • date - Data
  • email - E-mail
  • url - URL
  • boolean - Sim/Não (checkbox)
  • select - Seleção (dropdown)

Exemplos:

nome:text:Nome
preco:number:Preco
descricao:textarea:Descricao
data_nascimento:date:Data de Nascimento
email:email:E-mail
site:url:Website
ativo:boolean:Ativo
